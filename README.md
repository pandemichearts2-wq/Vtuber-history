# Graduate History 登録フォーム統合版

## 今回の変更

- 「新規登録を申請する」と「思い出の動画を登録する」を同じ登録フォームへ統合
- 独立していた「思い出の動画を登録する」タブを撤去
- 登録フォーム上部に次の3つの開閉ボタンを追加
  - メイン情報登録
  - 動画の登録
  - さらに詳細情報の登録
- 各ボタンを押した時だけ、その登録フォームを表示
- 動画登録からVTuber検索・VTuber選択を撤去
- メイン情報または詳細情報を入力する場合、活動名は必須
- VTuber名なしで動画だけを申請可能
- メイン情報と動画を同時に入力した場合は、1件の申請としてまとめて送信
- 管理画面でも、情報申請に含まれる動画内容を確認可能

## GitHubへ上書きするファイル

- `register.html`
- `register.js`
- `styles.css`
- `video-register.html`
- `admin.html`
- `admin.js`

`video-register.html` は、旧URLから統合済み登録ページの「動画の登録」を開くために残しています。

## Apps Script

1. `AppsScript-Code.gs` の内容で現在のApps Scriptを全置換
2. 保存
3. 「デプロイ」→「デプロイを管理」
4. 既存ウェブアプリを編集
5. 「新バージョン」でデプロイ

動画の種類に「歌ってみた」「オリジナルソング」が未追加の場合は、Apps Script置換後に `setupSheets` を一度実行してください。
